# 個人開発あるある分岐ゲーム

AIを相棒に、1年間の個人開発を生き抜く育成分岐ゲームです。コードが書けない主人公が、相棒AIと一緒にツールを作って公開していく1年を、選択肢で進めていきます。

ブラウザでそのまま遊べます：
https://tk030-lotto.github.io/indie-dev-aruaru-game/

## 遊び方
1. 相棒AIを5人から1人選びます（月額・得意分野・クセがそれぞれ違います）
2. 12ヶ月間、各月の出来事にコマンド（選択肢）で対応していきます
3. お金と「やる気」が尽きないように進めると、1年の終わりにエンディングを迎えます

- エンディングは7種類。到達したエンディングは図鑑に残ります
- 途中で「イベント」が割り込むこともあります
- 進行はブラウザ内に自動保存され、「つづきから」再開できます

## 動作環境
- モダンブラウザ（Google Chrome、Microsoft Edge、Safari、Firefox）
- スマートフォン、タブレット、PCの各画面サイズに対応しています

## 外部通信
通信しません。ゲームの処理はすべてお使いのブラウザ内で行われ、データが外部サーバーへ送信されることはありません。

## 制限・注意
- **セーブデータについて**: 進行状況はブラウザ内（localStorage）に保存されます。ブラウザのデータを削除したり、別のブラウザ・別のURLで開いたりすると引き継がれません。
- **登場するAIの名前について**: 相棒AIの名前は、実在のAIサービスをもじったパロディです。各サービスおよび提供企業とは関係ありません。
